几何定义与工厂复核要点

下边 y = (R/L)x，上边 y = (R/L)x + V。垂直斜边净宽 = V / √(1 + (R/L)²)。每段轮廓是两条平行边与两端切口的交点；局部轮廓平移到包络左下角原点。

合并 DXF 按 P01、P02… 从左到右排列，各块包络间留 100 mm，仅作文件排列，不是加工间隙。不含尺寸文字、切缝补偿、坡口、折弯、孔位或连接构造。

生产前复核：现场基准及左右方向、尺寸与容差、斜切口伸出、拼接方式、板材规格与排料、切缝补偿。钢密度按 7850 kg/m³ 估重。此工具不判断栏杆规范、承载或结构安全。

PWA 需 HTTPS 或电脑 localhost。普通局域网 HTTP 可在手机浏览器使用，但不能保证安装或离线。浏览器首次成功缓存后可离线使用；参数只在本机保存，建议另存 JSON 备份。
